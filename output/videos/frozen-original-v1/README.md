# Simulator development previews

Each clip shows the first five seed-2026 development scenarios, in order, for
the selected frozen model. These are simulator recordings with the original
heading formatter, not the later corrected deployment and not population scores.

- sa-first-five.mp4: single controlled aircraft, 38.4 seconds.
- ma-first-five.mp4: ten controlled aircraft, 44.8 seconds.

The source replays matched all nine saved metrics exactly for every aircraft.
MP4 conversion preserves the source duration and readable outcome cards. Both
complete videos decode without errors, and both final cards were inspected.
manifest.json records source and output hashes, model identities and commands.

The SA reel includes an arrival with 41 seconds of conflict exposure in its
fifth scenario. Arrival alone must not be described as a safe outcome.
